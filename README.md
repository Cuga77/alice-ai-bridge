# alice-ai-bridge

Мост между навыком **Яндекс Алисы** и любой LLM с OpenAI-совместимым API:
локальной (Ollama, LM Studio, vLLM) или облачной (OpenAI, OpenRouter и т. п.).

Сервис принимает вебхуки от Яндекс Диалогов, отправляет вопрос пользователя в
`/chat/completions` и возвращает Алисе ответ обычным текстом.

## Возможности

- Один файл, только стандартная библиотека Go, без зависимостей.
- Длинные ответы частями. Алиса ждёт навык около 3 с, поэтому мост через ~2.5 с
  отдаёт готовые законченные предложения и спрашивает «Продолжить?», а модель тем
  временем генерирует дальше. Следующая часть — по «дальше», «да», «ещё».
  Новый вопрос обрывает недосказанный ответ.
- История диалога в памяти (последние `HISTORY_TURNS` пар реплик, хранится 10 минут).
- Ограничение частоты запросов на пользователя (`RATE_PER_MIN`).
- Очистка ответа от markdown; пункты списков превращаются в предложения.
- Служебные команды:
  - `хватит`, `выйти`, `стоп` — завершить сессию;
  - `забудь`, `начни сначала`, `новый диалог` — сбросить историю;
  - `дальше`, `продолжи`, `продолжай`, `ещё`, `да`, `давай` — следующая часть ответа;
  - `ping` — проверка, ответ `pong`.

## Как это устроено

```
Станция / приложение Яндекса
        │
Яндекс Диалоги ──HTTPS──▶ туннель (tuna, cloudflared, …) ──▶ мост :8080/alice ──▶ Ollama :11434
```

Яндекс обращается к навыку по публичному HTTPS-адресу. Если мост запущен на
домашнем компьютере, нужен туннель, который выдаст такой адрес.

## Запуск

Понадобятся Go (версия — см. `go.mod`), Docker с Compose и аккаунт Яндекса.

### 1. Ollama

```bash
docker compose up -d
docker compose logs -f ollama-pull   # дождаться, пока модель скачается
```

Поднимаются два сервиса:
- `ollama` — сервер на `127.0.0.1:11434`, модели хранятся в volume `ollama`.
  Модель не выгружается из памяти (`OLLAMA_KEEP_ALIVE=-1`): холодная загрузка
  не укладывается в таймаут Алисы.
- `ollama-pull` — одноразовый: скачивает модель, прогревает её и завершается.

По умолчанию ставится `gemma3:1b`. Другая модель задаётся через `LLM_MODEL`
(переменная окружения или строка в файле `.env`) — см. [Выбор модели](#выбор-модели).

Если Ollama уже установлена в системе, этот шаг можно пропустить: достаточно
`ollama pull gemma3:1b`.

### 2. Мост

```bash
go run .
# listening on :8080/alice, llm: http://localhost:11434/v1 model=gemma3:1b
```

Проверка:

```bash
curl -s localhost:8080/alice -d '{"request":{"command":"привет"},"session":{"session_id":"s1","user_id":"u1"}}'
```

Для постоянной работы можно собрать бинарник: `go build -o alice-ai-bridge . && ./alice-ai-bridge`.

### 3. Публичный адрес

Если у сервера уже есть домен с HTTPS, настройте обратный прокси на `localhost:8080`
и переходите к следующему шагу. Иначе запустите туннель, например:

- **[tuna](https://tuna.am)** (нужна регистрация, хорошо работает из России):
  ```bash
  tuna http 8080
  ```
- **cloudflared** (без регистрации):
  ```bash
  docker run --rm --network host cloudflare/cloudflared:latest tunnel --protocol http2 --url http://localhost:8080
  ```
  `--protocol http2` нужен, если включён VPN: через него QUIC часто не проходит
  и туннель постоянно переподключается. Учтите, что серверы Яндекса не всегда
  могут достучаться до `*.trycloudflare.com`.

Туннель выдаст адрес вида `https://xxxx.ru.tuna.am`. Webhook навыка — этот адрес
плюс `/alice`. На бесплатных тарифах адрес обычно меняется при каждом перезапуске
туннеля, поэтому для постоянной работы зарезервируйте фиксированный поддомен.

### 4. Навык в Яндекс Диалогах

1. Откройте [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) →
   «Создать диалог» → «Навык».
2. Заполните настройки:
   - **Название** — по нему навык запускают. Слишком общие названия
     («Умный помощник») модерация может не пропустить.
   - **Webhook URL** — `https://<адрес-туннеля>/alice`.
   - **Тип доступа** — «Приватный», если навык нужен только вам.
   - **Примеры запросов** — каждая строка содержит фразу целиком, с названием:
     ```
     Запусти навык Мой гид
     Спроси у навыка Мой гид, что посмотреть в Петербурге
     ```
   - **Активационные имена** — необязательно; нужны, если Алиса плохо
     распознаёт название.
   - Иконка, описание, категория, email — обязательны для публикации.
3. Сохраните и проверьте на вкладке «Тестирование».
4. Нажмите «Опубликовать». Приватные навыки проходят упрощённую проверку —
   обычно от нескольких минут до пары часов.

### 5. Запуск на Станции

> «Алиса, запусти навык Мой гид»

Приватный навык доступен только в аккаунте Яндекса, в котором он создан.
Станция должна быть привязана к этому же аккаунту — проверить можно в приложении
«Дом с Алисой». Если Станция привязана к аккаунту другого члена семьи, создайте
навык под его аккаунтом: мост менять не нужно. Либо предоставьте ему доступ в вкладке 'Доступ'.

Навык работает, пока запущены Ollama, мост и туннель.

## Выбор модели

Алиса ждёт ответа около 3 с, поэтому важна скорость модели, а не только качество.

Смена модели:

```bash
LLM_MODEL=qwen3:0.6b docker compose up -d   # скачать и прогреть
LLM_MODEL=qwen3:0.6b go run .               # запустить мост с ней
```

> **qwen3 сначала «рассуждает»**, и ответ не укладывается в лимит Алисы.
> Отключите рассуждения: `LLM_REASONING_EFFORT=none`.

Управление моделями:

```bash
docker compose exec ollama ollama list       # скачанные модели
docker compose exec ollama ollama ps         # загруженные в память
docker compose exec ollama ollama rm <model> # удалить (иначе так и будет занимать RAM)
```

### Облачная модель

```bash
LLM_BASE_URL=https://api.openai.com/v1 \
LLM_API_KEY=sk-... \
LLM_MODEL=gpt-4o-mini \
go run .
```

## Если не работает

| Симптом | Что проверить |
|---|---|
| Мост отвечает «Не получилось ответить» | Запущена ли Ollama и скачана ли модель: `docker compose exec ollama ollama list` |
| На первый вопрос всегда «Ещё думаю» | Модель слишком медленная — возьмите меньше; для qwen3 задайте `LLM_REASONING_EFFORT=none` |
| В консоли Диалогов «empty response» | Запрос не дошёл до моста: проверьте Webhook URL (адрес туннеля мог смениться, в конце должно быть `/alice`) и что туннель запущен |
| Туннель постоянно переподключается | Мешает VPN: для cloudflared добавьте `--protocol http2` или исключите туннель из VPN |
| Станция не находит навык | Навык опубликован? Станция привязана к тому же аккаунту, что и консоль Диалогов? |

## Настройки (переменные окружения)

| Переменная             | По умолчанию                              | Описание                                         |
|------------------------|-------------------------------------------|--------------------------------------------------|
| `LLM_BASE_URL`         | `http://localhost:11434/v1`               | Базовый URL OpenAI-совместимого API              |
| `LLM_API_KEY`          | —                                         | Ключ API (заголовок `Authorization: Bearer`)     |
| `LLM_MODEL`            | `gemma3:1b`                               | Имя модели                                       |
| `LLM_SYSTEM`           | `Отвечай по-русски, кратко`               | Системный промпт                                 |
| `LLM_REASONING_EFFORT` | —                                         | Передаётся как `reasoning_effort`; для qwen3 — `none` |
| `LLM_MAX_TOKENS`       | `300`                                     | Лимит токенов всего ответа                       |
| `LLM_TIMEOUT_MS`       | `2500`                                    | Сколько ждать модель перед ответом Алисе, мс     |
| `LLM_GEN_TIMEOUT_MS`   | `60000`                                   | Максимальное время генерации всего ответа, мс    |
| `CHUNK_RUNES`          | `600`                                     | Максимальная длина одной части ответа, символов  |
| `HISTORY_TURNS`        | `5`                                       | Сколько пар «вопрос–ответ» помнить               |
| `RATE_PER_MIN`         | `10`                                      | Запросов в минуту на пользователя                |
| `LISTEN_ADDR`          | `:8080`                                   | Адрес HTTP-сервера                               |
| `WEBHOOK_PATH`         | `/alice`                                  | Путь вебхука                                     |

## Остановка

```bash
docker compose down      # остановить Ollama, модели остаются в volume
docker compose down -v   # остановить и удалить скачанные модели
```
